# 로봇 교장선생님 구하기! (대교초 SW·AI 행사용 웹 게임)

v1.3 시험 버전. 2026 교실 배치도·항공사진·학교 사진을 바탕으로 실제 대교초 맵을 만들었다.

## 맵 (실제 학교 기준)

- 바깥: 선생님이 보내 준 항공사진(좌우 뒤집은 방향)을 좌표 그대로 따라 그렸다. 항공사진 px → 칸 = ((x-80)/20, (y-30)/20).
  건물은 지붕 모양(다각형) 그대로 칸을 채우고, 각 세로줄 아래쪽을 정면(벽·창문)으로 그린다(`Sprites.drawBlock`).
  서쪽: 강당·식당 건물, 정문, 서쪽 주차장·다목적구장 / 가운데: 후관(동쪽 끝이 비스듬히 꺾임), 안뜰(정자·2층 연결통로·달팽이 그림·모래 놀이터), 본관(동쪽 끝 꺾임, 남서쪽 곡선 건물), 중앙현관 유리 차양, 스탠드, 트랙·인조잔디 / 동쪽: 체육시설(농구장)·스탠드, 큰 주차장(사선 울타리), 후문 / 북쪽: 주차장, 야외학습장, 미로 그림·암석원.
- 실내: 배치도 좌표로 만든 뒤 바깥 방향에 맞게 좌우를 뒤집는다(`mirror`). 배치도 위쪽 줄 = 운동장 쪽(남), 아래쪽 교실 줄 = 안뜰 쪽(북).
- 맵 연결 검사: 모든 문·계단·연결통로가 이어지고, 모든 NPC·물건에 걸어서 갈 수 있는지 자동으로 확인했다.

## 게임 구성

- **미션 순서도**(화면 왼쪽): 30분·탐험 `1 정문 → [2 과학실 | 3 도서관] → 4 방송실 → [5 컴퓨터실 | 6 운동장] → 7 창고 → 재부팅`
  10분: `1 → [3 | 4] → 6 → 7 → 재부팅` (2층 없이 부품 5개). 괄호 안은 어느 쪽 먼저 해도 된다. 순서도를 누르면 노란 별이 길을 안내한다.
- **미션 종류**: 1 퀴즈(문제 풀에서 3개) · 2 AI 이름표 고치기 · 3 책장 단서 + 퀴즈 · 4 암호 신호 풀기(저학년 모양 암호, 고학년 이진수) · 5 로봇 코딩(고학년은 반복 블록) · 6 놀이 기구 단서 + 정렬 자물쇠 · 7 어두운 창고에서 손전등으로 쪽지 3장 + 전구 블록코딩 · 마지막 로봇 교장선생님 재부팅(디지털 시민 OX 3문제)
- **잠긴 문과 아이템**: 출입 카드(본관 현관) · 컴퓨터실 열쇠 · 창고 열쇠 · 손전등. 탐험 모드는 문이 모두 열려 있다.
- **힌트 토큰**: 3개로 시작. 다 쓰면 힌트 한 번에 기록 +1분. 서브 미션(보건·영양사·전학생) +2개씩, 개나리 꽃 10송이 +1개, 도감 완성 +2개(한 번).
- **이어하기**: 같은 이름·모드로 다시 들어오면 하던 곳부터. 남은 시간은 계속 흐른다.
- **수집·칭호**: 개나리 꽃 10송이(교화) → "희망의 개나리 배지"와 칭호, 도감 31명 완성 → 칭호 "대교 느티나무 탐험가"(교목). 칭호는 캐릭터 머리 위에 보인다.
- **i 팻말**: 장소마다 설명 팻말이 있다 (관리자 화면에서 글을 고칠 수 있다).

## 실행

- `python3 build.py` → `dist/` 에 `index.html`, `manifest.webmanifest`, 아이콘이 만들어진다. `index.html`을 브라우저로 열면 바로 실행된다.
- 관리자 화면: 주소 끝에 `#admin`을 붙이거나, 입장 창 아래 "v1.0 시험 버전" 글자를 두 번 클릭한다. 처음 들어가면 비밀번호를 정한다.
- 자동 테스트: `python3 tests/smoke.py desktop 4 m30` (기기 desktop|mobile, 학년, 모드 m30|m10). 미니게임까지 실제 버튼을 눌러 클리어하고 `tests/shots/`에 화면을 저장한다.
- 콘텐츠 기본값을 크게 바꿀 때: `tools/make_content.js`를 고치고 `node tools/make_content.js` → `src/content.js`가 다시 만들어진다. (평소 문제·대사 수정은 관리자 화면에서)

## 서버 연결 (Supabase) — 모든 기기의 기록을 한곳에 모으기

지금은 기록·랭킹·접속자 수가 기기(브라우저)마다 따로 저장된다. 아래를 하면 학교 전체가 같은 랭킹을 본다.

1. supabase.com 가입 → New project (지역: Northeast Asia (Seoul))
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사해 `config.json`에 넣는다
   ```json
   { "supabaseUrl": "https://xxxx.supabase.co", "supabaseAnonKey": "eyJ..." }
   ```
4. `python3 build.py` → `dist/` 폴더를 Vercel 등에 올린다 (Vercel: New Project → 폴더 업로드, 또는 GitHub 연결)
5. **배포하자마자 `주소#admin`에 들어가 관리자 비밀번호를 정한다.** (처음 들어온 사람이 정하게 되어 있으므로 학생보다 먼저!)
   비밀번호를 잊으면 SQL Editor에서 `delete from rp_settings where key = 'admin_hash';` 후 다시 정한다.

서버 쪽 보안: 표는 학생 브라우저가 직접 읽거나 쓸 수 없고, `rp_` 함수만 부를 수 있다. 미션 순서와 기록 시간은 서버가 직접 확인·측정한다. anon 키는 공개되어도 되는 키다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `src/content.js` | 퀴즈·대사·힌트·미니게임 설정 기본값 (저학년 `low` / 고학년 `high`) |
| `src/world.js` | 대교초 맵: 바깥, 본관 B·1~4층, 후관 1~4층 (배치도 px 좌표 → 칸) |
| `src/sprites.js` | 픽셀아트 타일·캐릭터·사물을 코드로 그림 |
| `src/game.js` | 엔진: 이동·점프, 충돌, 카메라, 조이스틱, 미니맵, 길잡이 별, 낮·밤, 어두운 방·손전등, 꽃가루 |
| `src/minigames.js` | 미니게임 5종 (이름표·암호·로봇 코딩·정렬·전구 블록코딩) |
| `src/main.js` | 게임 흐름: 입장, 이어하기, 순서도, 미션, 힌트 토큰, 아이템·잠금, 수집, 재부팅, 클리어 |
| `src/ui.js` | 대화창, 퀴즈(해설·힌트), 순서도, 수첩, 팻말, 랭킹, 클리어 화면 |
| `src/admin.js` | 관리자: 기록 조회·CSV·삭제, 랭킹 초기화, 문제 풀·대사·팻말·미니게임 수정 |
| `src/store.js` | 저장소: `LocalStore`(기기 저장) / `ServerStore`(Supabase) — config.json에 따라 자동 선택 |
| `src/util.js` | 공용 함수, 미션 코스 규칙 (`supabase/schema.sql`의 `rp_course`와 같아야 한다) |
| `supabase/schema.sql` | 서버 표·함수 |
